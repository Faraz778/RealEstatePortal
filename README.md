# Online Real Estate Portal

A full-stack Real Estate Portal built with ASP.NET Core MVC, featuring three separate panels for Admin, Agent, and Private Seller.

## Tech Stack
- ASP.NET Core MVC
- C#
- Entity Framework Core (Code First)
- SQL Server
- Bootstrap 5

## Features
- Secure session-based login with role-based access control
- Three panels: Admin, Agent, and Private Seller
- Complete CRUD operations for property listings and users
- Advanced property search and filter system
- Agents and sellers can post property ads directly
- Migrations-based database management
